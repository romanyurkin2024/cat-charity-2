# QRKot — благотворительный фонд поддержки котиков

API для фонда, который собирает пожертвования на целевые проекты для котиков: корм, лечение, обустройство мест обитания.

Пожертвования **распределяются по проектам автоматически**. Деньги идут в открытые проекты по очереди: сначала в самый старый, потом в следующий. Когда проект набрал нужную сумму, он закрывается. Если после этого у пожертвования остались деньги, они ждут следующий проект.

## Возможности

- Суперпользователь создаёт, редактирует и удаляет целевые проекты.
- Зарегистрированный пользователь делает пожертвования и видит список своих.
- Новый проект сразу забирает свободные деньги из прошлых пожертвований. Новое пожертвование сразу уходит в открытые проекты.
- Закрытый проект нельзя редактировать. Проект, в который уже вложены деньги, нельзя удалить.
- Авторизация по JWT-токену.

## Стек

Python 3.12 · FastAPI · SQLAlchemy 2 (async) · Alembic · Pydantic 2 · FastAPI Users · SQLite (aiosqlite) · pytest

## Как запустить

Клонировать репозиторий и перейти в папку проекта:

```bash
git clone git@github.com:<твой-github>/cat-charity-2.git
cd cat-charity-2
```

Создать и активировать виртуальное окружение, установить зависимости:

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: source venv/Scripts/activate
pip install -r requirements.txt
```

Создать в корне проекта файл `.env`:

```env
DATABASE_URL=sqlite+aiosqlite:///./fastapi.db
SECRET=придумайте-длинную-случайную-строку
```

Применить миграции и запустить сервер:

```bash
alembic upgrade head
uvicorn app.main:app --reload
```

## Документация API

После запуска документация доступна по адресам:

- Swagger: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## Основные эндпоинты

| Метод | Адрес | Что делает | Доступ |
|---|---|---|---|
| GET | `/charity_project/` | Список всех проектов | Все |
| POST | `/charity_project/` | Создать проект | Суперпользователь |
| PATCH | `/charity_project/{project_id}` | Изменить проект | Суперпользователь |
| DELETE | `/charity_project/{project_id}` | Удалить проект | Суперпользователь |
| POST | `/donation/` | Сделать пожертвование | Пользователь |
| GET | `/donation/my` | Мои пожертвования | Пользователь |
| GET | `/donation/` | Все пожертвования | Суперпользователь |
| POST | `/auth/register` | Регистрация | Все |
| POST | `/auth/jwt/login` | Получить токен | Все |

### Пример: создать проект

```json
POST /charity_project/
{
  "name": "Корм для котиков",
  "description": "Покупаем корм на зиму для приюта",
  "full_amount": 10000
}
```

### Пример: сделать пожертвование

```json
POST /donation/
{
  "full_amount": 500,
  "comment": "Для котиков"
}
```

## Как стать суперпользователем (локально)

Зарегистрируйтесь через `/auth/register`, затем выполните в корне проекта:

```bash
sqlite3 fastapi.db "UPDATE \"user\" SET is_superuser = 1 WHERE email = 'ваш@email.com';"
```
